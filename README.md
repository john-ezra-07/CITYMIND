CITYMIND: Multi-Agent Digital Twin for Urban Mobility
CITYMIND is an AI-powered digital twin designed to simulate, analyze, and predict the cascading impacts of urban interventions before they are implemented in the real world.

Instead of looking at traffic or transit in isolation, CITYMIND models the entire urban ecosystem—simulating the interactions between commuters, public buses, emergency vehicles, EV charging stations, and traffic signals.

🚀 Key Features Included in the Prototype
Interactive Multi-Agent Canvas: Real-time visual simulation of commuters, buses, emergency units, and EV vehicles navigating urban road and transit networks.

Dynamic Scenario Testing: Instant simulation triggers for real-world stress events:

🚧 Major Road Closure (triggers cascading rerouting and congestion)

🚌 Fleet Surge (adds capacity to alleviate public transit bottlenecks)

🏟️ Stadium Mega-Event (simulates localized sudden passenger influxes)

⚡ EV Charging Spike (models power grid/charging station queue gridlocks)

🚑 Emergency Dispatch (prioritizes emergency routing through congested corridors)

Live Analytics & Telemetry: Real-time metrics tracking average delays, public transit load, EV queue wait times, and overall network congestion indices.

AI Decision Co-Pilot: Generative policy insights that answer the core question: "What will happen to the entire mobility system if we change this?"

🛠️️ Technology Stack
Frontend Engine: HTML5 Canvas, Tailwind CSS for modern responsive UI styling.

State & Simulation Logic: Vanilla JavaScript (ES6+) implementing custom asynchronous multi-agent behavior loops, spatial node routing, and event-driven metric aggregation.

Icons & Typography: Lucide Icons and Inter font family via CDN.
